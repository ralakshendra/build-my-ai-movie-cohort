FIVE CONNECTED STAGES

Workflow and course settings

  1. Build a reusable character

    OpenArt All Tools → Create Character. The course demonstrates Build Your Character from scratch and a Start from an image route that accepts up to four references. Generate four variations, select one, set it as a character, name it, and save it.

    Source: Module 1, Character Creation.

  2. Create a product-in-hand frame

    Use the saved character as a visual reference and attach a product image. The demonstration uses OpenArt with GPT Image 2. The linked course specifies 9:16, 4K, and four variations. Check the current interface before spending credits.

    Source note: Module 2 provides incomplete starter wording for this image. It is not a complete reusable prompt; add the scene, product, and accurate label details yourself.

  3. Generate talking A-roll

    The course demonstrates Kling 3.0 Omni with the product frame as a start frame, no end frame, and audio enabled. Replace the sample dialogue and all product claims with truthful, authorized copy.

    Source: Module 3, Lip Sync.

  4. Add product and use-case B-roll

    Make a product close-up image from the product-in-hand frame. For an optional use-case clip, the course describes a five-second Kling example with audio off and product references. Its module labels the mode video-to-video, while the supplied class transcript says text-to-video. Verify the current mode and test briefly.

    Source: Module 4, Parts 1 and 2.

  5. Edit and export

    The course uses Filmora and a 9:16 project. Place talking A-roll on the base track and B-roll above it where it adds information or covers a cut. Keep transitions simple, keep dialogue clear, add music only if useful, and use Foley when it supports the action.

    Source: Module 5, Editing.

Module 3 talking A-roll prompt
Starting from the current frame, the woman begins speaking directly to the lens with an energetic and warm UGC-style persona.
DIALOGUE: "People always ask me how I still look 20 even though I'm almost 50. Yeah, you heard that right. Lumière Radiance Face Serum. I've been using this serum every single day and night for the past 20 years."
TECHNICAL MOTION CONSTRAINTS:
1. LIP-SYNC: Precise phoneme-based lip-syncing. Lips must close fully on "M", "P", and "B" sounds.
2. ANATOMICAL STABILITY: Maintain a fixed, single-row dental structure. No hallucination of extra teeth, overlapping gums, or shifting tooth shapes. Teeth must remain naturally occluded behind the lips, visible only through the jaw's natural hinge movement.
3. MUSCLE DEFORMATION: Realistic activation of the zygomatic (cheek) muscles and chin while speaking. No "floating" mouth; the lower face must move as a cohesive unit.
4. GESTURE: Subtle, organic hand movement while holding the Lumière serum bottle, ensuring the fingers do not morph or lose contact with the bottle.
5. CONTINUITY: Maintain the exact 4k skin texture, marble bathroom environment, and shallow depth of field from the start frame. No flickering or lighting shifts.

AI Filmmakers Cohort UGC Masterclass, Module 3. The dialogue and product details are fictional examples, not substantiated claims.

REVIEW BEFORE DELIVERY

Editing and quality notes

  • Keep the character, product shape, packaging, lighting, and label consistent.
  • Review mouth motion, teeth, hands, product contact, and audio before adding transitions.
  • Use B-roll only when it adds a detail or clarifies the action.
  • Make product claims only when they are accurate, substantiated, and authorized.
  • Export in 9:16, then follow the cohort’s current sharing instructions.
