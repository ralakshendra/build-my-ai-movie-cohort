## Homework Google Docs standard

- Use the approved Build My AI Movie Studio website identity: Inter typography, orange accents, charcoal headings, warm-white page background, and the approved avatars from `assets/avatars/BMAMS-avatar-library-final-20261008/`.
- Use approved avatars generously (about three to five per homework when the content supports it). Keep each figure on the right near its related heading or visual, with its face or gesture directed into the section. Reduce size or reposition figures when they feel detached; never cover prompts, answer areas, or links.
- Preserve every official instruction, prompt, table dimension, submission requirement, and factual detail. Replace filler such as “Add your answer here” with a clear label and genuinely usable blank writing space. Use lightly shaded answer areas and enough room for the expected response.
- Use native Google Docs checkboxes for actionable review/checklist items where supported. Use native dropdowns only when the connected Docs tools can create and verify them. If that capability is unavailable, use the checkbox approach shown in the approved prototype and disclose the limitation; never imitate a dropdown with styled text and claim it is native.
- Before changing an official homework Doc, make a clearly titled backup copy. Treat backups and student-owned copies as noncanonical; never place their links on the site. Keep exactly one verified canonical homework Doc link per homework assignment across the homepage, schedule, session guide, playbook, and homework page.
- Audit Drive results and all site references for duplicate or stale homework links before finishing. Preserve student work and other meaningful copies; remove only links that point to a noncanonical Doc, and do not permanently delete Drive files without explicit direction.
- Review the Google Doc after editing and check page flow, answer areas, checkbox behavior, avatar placement, and all original instructions before updating the website’s canonical homework link references.
