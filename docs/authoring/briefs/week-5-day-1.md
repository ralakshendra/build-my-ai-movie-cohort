- Bring the supplied property images and a shared team file location.
- Use a Chrome image-conversion extension only when WebP is unsupported.
- Optional still preparation: Nano Banana or GPT Image 2.
- Motion: Kling 3.0 Omni was demonstrated; another understood image-to-video model is allowed.
- Edit and music: Filmora.
- Task 1 selects and validates property references. Evidence: source links/files and a continuity check.
- Task 2 prepares only the missing views. Evidence: approved still links and what changed.
- Task 3 generates purposeful walkthrough motion. Evidence: model, mode, settings, frame inputs and approved clip links.
- Task 4 edits one team film. Evidence: final link, review notes and reflection.

1. The team can link the property reference images used.
2. Stills and motion keep the property recognizable and architecture stable.
3. Movement is purposeful; warped or unusable clips are fixed or removed.
4. The Filmora edit forms one walkthrough with music and avoids filler.
5. The team produces one final video of about one minute or less.
