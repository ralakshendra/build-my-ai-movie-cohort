The Structured Brand-Story Pipeline

Instructor: Alexx Roy, Founder, AI FilmCraft

Core sequence: Brief → character sheet → colour palette → mood board → screenplay → shot list → generation.

1. Two screenplay methods

Direct

  • Fast screenplay from a brand brief.
  • Useful when speed matters or the LLM already has the full brand context.
  • Risk: limited understanding of backstory, emotion and connection point.

Structured

  • Character sheet first.
  • Colour palette and mood board next.
  • Screenplay generated from those references.
  • Best alignment for a professional brand story workflow.

2. Prompt structure

1Camera shot of the subject
2Texture / realism
3Lighting
4Movement, if needed
5Consistency or mood keywords last

3. Rule of three failures

If three generations in a row fail, change the approach instead of repeating the same prompt.

  • Change camera angle.
  • Change camera position.
  • Change how the character is positioned inside the frame.

4. Tool map

ToolRole in this workflow
Google FlowHeadshot, character sheet and mood board image generation. Use the Image option and Nano Banana Pro.
GeminiGenerate palette options and the visual colour board.
ClaudeGenerate, review and structure the screenplay and shot shortlist.
Google DocsStore, edit and share the structured shot list.
SunoMusic exploration, covered later.

5. Production sequence

1Prepare multiple headshots.
2Create the headshot / character sheet in Flow.
3Fix face inconsistency by tagging the uploaded reference when needed.
4Generate and select the brand colour palette in Gemini.
5Create the mood board in Flow.
6Attach character sheet + mood board to Claude and generate the screenplay.
7Review the screenplay, then convert it into a structured landscape shot list.
8Organize every asset for continued production and later portfolio building.

6. Generation after the blueprint

Once the structured base is ready, continue with the remaining production stages. The class described a virtual world / location board, multi-angle hero generation, then A-roll, B-roll and music. A-roll is the main action. B-roll includes supporting or flashback details.

7. Troubleshooting

ProblemFirst fix
Face does not matchAdd the strict facial-feature retention instruction and tag the source image.
Wrong gender / random lookCheck the uploaded image, model and project. Clear cache and retry if needed.
No Nano Banana ProSwitch from Video to Image.
Gemini does not create the boardAsk explicitly for the image and enable the image feature.
Output drifts from a desired formatAttach a reference screenshot and ask the model to regenerate in that format.

8. Credit discipline

Do not rush into experimentation. The session explicitly asked students to save credits until the dedicated experimentation period later in the cohort.
