01 / CORE WORKFLOW

Build the frame before the motion.

Every shot starts from a strong image. The hero image becomes the visual anchor for the rest of the sequence.

01

Hero image

Create the first product image in OpenArt using Nano Banana Pro. Use sharp product and scene references.

02

Matching frames

Move from wide or aerial to mid, close-up and extreme close-up. Attach the hero plus the immediately previous frame when building continuity.

03

Image to video

Use the generated image as the start frame. Use an end frame only when the two frames describe a believable transition.

02 / IMAGE GENERATION

Reference discipline.

References strongly influence the generated result.

Every image generation

  • Use 16:9.
  • Use 2K for the demonstrated workflow.
  • Generate 3 variations and choose the strongest.
  • Use high-quality references rather than pixelated screenshots.
  • Check that the full prompt copied correctly.

Continuity pattern

  • Hero image sets product, lighting and colour.
  • For a new angle, attach the previous frame plus the hero.
  • Do not attach every earlier frame.
  • When swapping a character or vehicle, remove old keywords that could pull the model back to the previous reference.

05 / TROUBLESHOOTING

Fix the cause.

Most problems came from references, continuity, prompts or model limitations.

Product drifts

Regenerate and strengthen the product reference. If needed, add the reference tag after the relevant prompt line.

Reverse motion

Change vehicle wording from riding to moving, regenerate, or reverse the clip in post.

Unrelated transition

Use start frame only. The model cannot reliably invent a believable bridge between unrelated frames.

Bad section in a good clip

Cut around it. Problems can be solved in editing.

Reference too small

Replace it with a larger, sharper image.

Prompt too long

Use Polish prompt or Enhance prompt when the model supports it.

06 / CREDIT RULE

Generate smart.

Prioritize iteration and selection rather than trying to perfect every first generation.
