DAY 2 / PRODUCTION RULES

Control the visual transition.

Day 2 is about building a believable sequence from images before adding motion. Use the frames to define the visual world and the prompt to guide movement.

01

Image First

Build a strong hero image before generating video. The hero becomes the visual anchor for the sequence.

02

Reference Continuity

Use the hero and the immediately previous frame to carry product, lighting, colour and visual identity forward.

03

Meaningful Frames

Use Start and End Frame Animation only when the two frames describe a believable visual transition.

04

Generate Smart

Start at 720p, use short 5 to 7 second generations and iterate before spending credits on an upscale.

Core rule: A video prompt cannot reliably repair unrelated start and end frames. Fix the visual relationship first, then generate the motion.
