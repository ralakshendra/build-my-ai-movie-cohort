SESSION OBJECTIVE

Create a fast, photorealistic advertisement by generating a hero product image, extending visual continuity across additional frames, and turning selected frames into short video shots using OpenArt.

01 / What You Are Practising

Complete the work in the same sequence used during the session.

  • Generate a hero product image that becomes the reference for the remaining frames.
  • Use visual references to guide product, character, object and colour consistency.
  • Generate additional frames that move from wider views toward closer shots.
  • Use OpenArt's start frame, end frame and start-and-end-frame animation workflow.
  • Apply the demonstrated video settings before generating.

03 / Video Generation

Images first. Then switch to Video and choose the appropriate frame-animation mode.

Switch from Image to Video.
Select Start and End Frame Animation when the shot requires both frames.
For a start-frame-only shot, use the start frame without adding an end frame.
Use the demonstrated Kling 3.0 model where instructed.
Turn audio OFF during generation.
Use roughly 5 to 7 seconds based on the activity in the shot.
Start with 720p for initial generations, then upscale if needed.
Keep variation at 1 for the demonstrated setup.
Check estimated credit consumption before generating.

04 / Continuity Check

Judge the sequence as one advertisement, not as isolated generations.

Product consistency

Does the product remain recognisable and visually consistent?

Visual continuity

Do the frames feel like they belong to the same advertisement?

Movement

Does the animation move naturally from the selected start frame?

Prompt quality

What did you change when the generation did not produce the intended movement?
