03 / Video Generation

Images first. Then switch to Video and choose the appropriate frame-animation mode.

Switch from Image to Video.
Select Start and End Frame Animation when the shot requires both frames.
For a start-frame-only shot, use the start frame without adding an end frame.
Use the demonstrated Kling 3.0 model where instructed.
Turn audio OFF during generation.
Use roughly 5 to 7 seconds based on the activity in the shot.
Start with 720p for initial generations, then upscale if needed.
Keep variation at 1 for the demonstrated setup.
Check estimated credit consumption before generating.
