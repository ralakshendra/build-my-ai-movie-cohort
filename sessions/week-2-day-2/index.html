Core concepts

Understand these five ideas and the rest of the session makes sense.

1. The workflow

  • Create images first, then animate them into video.
  • Animation methods: start frame plus end frame, start frame only, or end frame only (sometimes).

2. Why start and end frame is most reliable

  • The model only has to interpolate between two given frames.
  • Image to video hallucinates less than text to video.
  • It only works well when the two frames are related. A prompt cannot fix unrelated frames.

3. Hero image

  • The first product image you make. Every later frame uses it as a reference.
  • It keeps the bottle, colour palette and lighting consistent across all shots.

4. Reference images

  • The prompt leans toward attached references, so they are crucial.
  • Use high quality images. Screenshots can be pixelated and hurt output quality.
  • Finding references yourself is a skill you will need for your own projects.

5. Multi-shot continuity

  • Move inward like real cinematography: aerial or wide, then mid shot, close up, extreme close up.
  • For each new angle, attach the previous frame and the hero image.

Questions answered in class

Kids content setting on YouTube
Most kids watch from a parent account. Turning the kids option on hides the video from adult accounts, so leave it off for reach.
How will I get paid from YouTube?
Open studio.youtube.com and check Earnings on the left to see the eligibility criteria. Once met, you add payment details. YouTube emails you. You upload nothing.
Can I use my own product or brand?
Yes. Change the brand name inside the prompt (it sits in annotation) and swap references. If problems appear, help may be limited right away, but you can ask later.
How do I write my own prompts?
Use the prompt bank and study the structure. Modern models rewrite weak prompts internally, so you can type what you want or press Enhance prompt. Each project prompt in this course uses a different style, so read them all.
Can I edit an old prompt?
Yes. Open the earlier generation, copy its prompt and paste it into the configuration tab. You cannot edit within the same generation.
Can I use other image tools?
Yes, but avoid Gemini for this. Paid GPT Image saves credits.
Why not Veo 3.1?
Output quality follows training data. Google has more compliance layers, so you can't get this physics and realism, or some face replication, in Nano Banana Pro. Other models in OpenArt have lighter compliance. Newer models can reach it.
Wide shot to close up in one clip?
One prompt is enough, but Kling 3.0 struggles with big zoom effects. Omni models handle it. Covered in a future session. Save credits for now.
Class timing and recordings
Sessions often run an extra hour. If you're short on time, rely on the recording. Feedback sessions are not recorded, unless new techniques are shown. Find recordings through the WhatsApp group description, then Mother Sheet.
Can I compare with the original video?
Yes. The original ad will be shared with the video prompt reference.
Is week 8 content available early?
No. The syllabus is sequenced so complete beginners reach expert level step by step.
